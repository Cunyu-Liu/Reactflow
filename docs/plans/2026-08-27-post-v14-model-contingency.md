# Post-V14 model contingency — frozen before V14M3 score access

**Status:** `PRE_SCORE_CONTINGENCY_ONLY_NO_TRAINING_AUTHORITY`

**Frozen evidence boundary:** V1–V13 terminal results and the completed post-V13
route diagnostic. No V14M3 fold score, loss, per-puzzle effect, Gate direction or
external outcome was read while preparing this document.

**Authority effect:** none. V14 remains the only active model experiment. This
document cannot change V14, authorize V15, lower a Gate or turn a V14 failure
into a pass.

## 1. Focal question

If V14 masked-WT pretraining does not pass its complete seed-0 top-journal
screen, which *missing predictive capability* is still scientifically eligible
for one further model experiment?

The decision must distinguish four explanations that the V14 headline verdict
alone can otherwise blur:

1. the larger architecture is useful but self-supervised WT pretraining adds no
   increment;
2. pretraining adds transferable context but not enough to beat the historical
   point models;
3. both V14 models fail because independently encoding one construct cannot
   represent unseen-puzzle context;
4. point prediction is adequate and only the conditional residual distribution
   remains misspecified.

## 2. Located evidence before V14 scoring

- `LOCATED_EVIDENCE`: feature41 remains the dominant transferable baseline. It
  already contains exact mutant-versus-WT thermodynamic ensemble-change
  information.
- `LOCATED_EVIDENCE`: V11–V13 neural point models improved signed-delta MAE by
  roughly 9.8–10.1% versus feature41, but their increments over matched parents
  or nested nulls were approximately zero to 0.7% and did not satisfy the
  frozen attribution Gates.
- `LOCATED_EVIDENCE`: V11's useful effect was concentrated away from the edit
  site and where `abs(feature41)` was non-negligible. More shrinkage coordinates
  in V12 did not supply the missing margin.
- `LOCATED_EVIDENCE`: V13 exact-mutant re-encoding changed all four headline
  metrics by approximately zero relative to an identical WT-replay null. More
  mutation-sequence encoding is therefore not an eligible default route.
- `LOCATED_EVIDENCE`: V9/V10 demonstrated useful calibration and asymmetric
  residual signal, but later models remained point-limited. Additional scale,
  mixture or location capacity is not the default explanation.
- `LOCATED_EVIDENCE`: every puzzle contains eight outcome-blind WT constructs
  generated by different design methods for a shared puzzle target. V1–V14
  encode and predict these constructs independently; no registered rescue model
  lets a focal construct condition on the other seven WT sequence/reactivity
  contexts from the same unseen puzzle.
- `LOCATED_EVIDENCE`: historical contact/structure propagation, frozen RNA
  foundations, Vienna feature expansion, low-rank operators, noise weighting
  and coherent sign-magnitude factorization have already produced negative or
  sub-threshold complete evidence.

## 3. Remaining capability proposals

These are `IDEA` records, not findings or authorized candidates.

### P1 — Puzzle-set meta-context operator

- `IDEA`: encode the eight WT constructs belonging to one puzzle as a
  permutation-equivariant set at every shared full-sequence coordinate. A
  focal construct's parent-anchored increment may attend to outcome-blind V14
  states from the other seven constructs at the mutation source and each
  receiver coordinate. Metadata-only audit confirms all eight constructs in
  every puzzle share length, design interval and target structure.
- `NEW_CAPABILITY`: cross-construct conditioning inside an unseen puzzle. This
  differs from V11/V13/V14, which use only the focal construct, and from generic
  structure message passing, which propagates positions inside one construct.
- `ASSUMPTION`: variation across the eight designs contains information about
  the puzzle's structural regime and measurement difficulty that is not
  recoverable from one WT profile alone.
- `PREDICTION`: the cross-construct candidate improves signed and point-absolute
  metrics over an identical block-diagonal set encoder, with the largest gains
  on puzzles where V11–V14 residual transfer is heterogeneous.
- `FALSIFIER`: the complete candidate-minus-block-diagonal increment is below
  the existing 1–1.5% attribution margins, lacks a positive puzzle-level CI, or
  agrees in fewer than 14/20 puzzles.
- `MATCHED_NULL`: identical inputs, parameters, initialization, optimization
  and calibration, but the focal-query attention mask permits access only to
  its own construct tokens. No method ID, puzzle ID, held outcome or target mask
  is an input to either arm.
- `INITIALIZATION_PROTOCOL`: before point fitting, initialize only the new set
  operator with 200 epochs of outer-train masked-WT reconstruction. Candidate
  may use aligned non-focal WT profiles and the null remains self-only; both use
  the same 40% masks, temporary decoder, puzzle order and optimization budget.
  The imported V14 encoder and zero-initialized point head remain frozen, and
  mutant outcomes are unavailable to this stage.
- `PRIMARY_RISK`: the eight designs may be conditionally redundant, and the set
  model may memorize outer-train target motifs rather than generalize to an
  unseen puzzle.

### P2 — Frozen-point median-preserving quantile residual

- `IDEA`: only when every point Gate passes and CRPS or distribution-absolute
  error is the sole failed family, freeze the V14 point and learn a monotone
  conditional quantile function with its 0.5 quantile exactly fixed to the
  point prediction.
- `NEW_CAPABILITY`: nonparametric conditional tail shape optimized by integrated
  pinball/CRPS rather than another Gaussian scale/location mixture.
- `ASSUMPTION`: residual misspecification remains after the V10
  median-constrained asymmetric family, while the conditional median is already
  adequate.
- `PREDICTION`: CRPS and distribution-derived absolute-delta improve without
  changing any point prediction key by more than `1e-7`.
- `FALSIFIER`: no positive increment over a parameter-matched replay of the V10
  residual family, or any signed/point metric changes.
- `PRIMARY_RISK`: a flexible quantile surface may improve development CRPS by
  fitting tail noise and still fail independent external confirmation.

### P3 — Stop model rescue

- `DECISION_CANDIDATE`: if neither cross-construct transfer nor a genuine
  distribution-only bottleneck is supported by the complete V14 result, stop
  neural rescue. Preserve the strongest valid development baseline and return
  the paper to benchmark/measurement framing rather than inventing a third
  explanation from the same twenty consumed puzzles.

## 4. Mechanical routing after the complete V14 verdict

The first matching branch controls. All comparisons use the frozen
position-to-mutant-to-method-to-puzzle estimator and twenty held puzzles as the
only independent units.

1. **Exact `V14M3_TOP_JOURNAL_SCREEN_PASS`:** open only frozen V14M4 seeds 0–4.
   Do not run post-screen route diagnostics or create another model family.
2. **Artifact, target identity, coverage or aggregation failure:** this is an
   audit failure, not model evidence. Repair only the identified engineering
   fault and reproduce the same frozen universe; no new architecture is
   selected.
3. **Candidate beats feature41 and historical parents but fails the matched-null
   attribution Gates:** classify as `CAPACITY_WITHOUT_PRETRAINING_INCREMENT`.
   V14 remains terminal FAIL. P1 is the only eligible new point capability;
   neither a wider focal encoder nor another focal WT-pretraining schedule is
   allowed. P1's set-operator initialization is part of its matched
   cross-construct capability test, not a V14 retry.
4. **Candidate passes every candidate-versus-null attribution Gate but misses
   one or more historical point margins:** classify as
   `PRETRAINING_SIGNAL_INSUFFICIENT_FOR_TRANSFER`. P1 is eligible because the
   missing capability is unseen-puzzle context, not another masking objective.
5. **Candidate and null both miss historical point margins, or point effects
   fail direction/influence stability:** classify as
   `INDEPENDENT_CONSTRUCT_TRANSFER_LIMITED`. P1 is eligible only after one
   fixed, complete outer-train-only linear route probe shows at least 1% signed
   and point-absolute improvement, positive puzzle-level CIs and at least 14/20
   positive puzzles. Otherwise choose P3.
6. **All signed and point-absolute Gates pass; CRPS or
   distribution-absolute is the only failed headline family:** run one frozen
   post-score residual diagnostic. P2 is eligible only if a predeclared
   tail/quantile-asymmetry statistic has a puzzle-level CI excluding zero and
   at least 14/20 puzzles agree. Otherwise choose P3.
7. **V14M3 passes but V14M4 fails:** preserve the formal negative result and
   classify the signal as seed-unstable. Do not select seeds or create P1/P2
   from the same formal outcomes; return to P3 unless a new independent dataset
   becomes available.

No branch may authorize both P1 and P2. When point and distribution families
both fail, the upstream point/transfer failure controls and P1 precedes any
residual experiment.

## 5. Minimum amendment requirements for P1

If P1 becomes eligible, its amendment must freeze before training:

- one cross-construct candidate and one block-diagonal matched null;
- the same-fold V13 candidate seed-0 point as an immutable prediction anchor
  for both arms, selected here before V14 scoring rather than after observing a
  route result;
- the same-fold V14 candidate seed-0 encoder as an immutable outcome-blind
  representation for both arms, used regardless of V14's eventual score;
- a zero-initialized incremental point head so both arms replay the frozen V13
  parent at `1e-7` before training;
- one outer-train-only, 40%-mask, 200-epoch WT reconstruction stage with an
  exactly initialized 769-parameter temporary decoder; during this stage only
  the set mixer and decoder are trainable, and both arms must preserve parent
  replay at `1e-7` afterward;
- the decoder is frozen and removed downstream; point fitting then trains only
  the set mixer and incremental head;
- the exact set membership derived from outcome-blind puzzle metadata;
- no method-ID or puzzle-ID embeddings and no held target/error/mask access;
- a single fixed architecture, parameter count, optimizer, epoch count and seed
  universe;
- feature41 remains an explicit adapter input, while the frozen V13 parent is
  the point anchor; candidate and null use the same residual family and
  calibration protocol;
- seed-0 twenty-fold complete-before-score screen followed by seeds 0–4 only on
  exact PASS;
- all current top-journal margins versus feature41, terminal historical parents
  and the matched null, with coverage, LOO and influence Gates unchanged;
- an unconditional failure rule terminating cross-construct meta-context.
