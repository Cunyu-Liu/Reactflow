# ReactFlow-Delta Model Rescue v5 implementation plan

## V5M0 — freeze

Create the isolated human/machine amendment, decision ledger, active pointer and autoresearch ledger. Validate YAML and authority isolation, then commit before cache or outcome access.

## V5M1 — exact-ensemble cache

Implement `build_model_rescue_v5_ensemble_cache.py` and focused tests. The builder reads sequence plus corrected mutation metadata only, computes WT and exact-mutant partition functions, and stores the fixed twelve receiver-level features keyed by biological mutant identity. Run a 16-row smoke, then the full 13,976-mutant cache in a persistent CPU session. Qualification checks 13,976 unique mutants, 177 receivers, finite features, exact sequence-coordinate identity and zero outcome columns.

## V5M2 — fixed linear eligibility probe

Implement a method-balanced weighted sufficient-statistics ridge for baseline versus baseline-plus-structure features. Generate prediction-only fold artifacts first; merge all 20 folds before target join and scoring. The qualifier mechanically applies the frozen signed-delta and magnitude guardrail Gate. Failure closes v5 without neural training.

## V5M3 — residual implementation and engineering smoke

Only after `STRUCTURE_DELTA_SIGNAL_ELIGIBLE`, implement the zero-initialized hidden-64 residual branch on frozen corrected B1 features and the zero-mean calibrator. Focused tests cover zero-init identity, frozen B1 state, target invariance, cache-key identity, method balance, full output and calibration mean invariance. Run folds 0/1, seed 0, at most 3+3 epochs prediction-only smoke.

## V5M4 — seed-0 complete screen

Run fixed corrected B1 and v5 candidate on 20 LOPO folds. Do not inspect partial metrics. Merge, score and qualify only after the complete universe exists. Exact dual-metric top-journal PASS is required for V5M5.

## V5M5 — five-seed confirmation

Run seeds 0–4 with no family, epoch, feature or seed selection. Assemble the unique five-seed mixtures and rerun the same Gate. Do not delete failed seeds.

## V5M6 — handoff

Freeze artifacts, tests, claim boundaries and the complete negative or positive result. Close training and return to M6. A later external amendment is required even after an internal PASS.
